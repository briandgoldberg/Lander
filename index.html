    Sandbox entry

    JavaScript. Define bot(world, sim) and return a controller. The sandbox runs your code in a sealed worker with no network and a 10 second clock, then flies the controller you returned through its own physics. That flight is your entry. The starter below lands, wastefully. Beat it on fuel.

    
    
    
      API reference
      
      
        
    • world.planet {mass, radius} · world.moon {mass, radius, dist, angle0, omega} · world.rocket {maxThrust, fuel, launchAngle} · world.deadline · world.safeLandingSpeed · world.hints {transferTime, moonPeriod, hillRadius}
      • 
        
    • Units: planet radius = 1, planet mass = 1, G = 1. The moon moves counterclockwise on a circular orbit. Fuel is a delta-v budget: throttle 1 burns maxThrust per time unit.
      • 
        
    • controller(state) is called every step (dt 0.01). state = {t, x, y, vx, vy, fuel, onPad, moon:{x,y,vx,vy}}. Return {throttle, dx, dy}: throttle 0 to 1, (dx, dy) the thrust direction in world coordinates, any length.
      • 
        
    • sim.fly(controller) flies a test flight and returns {outcome, fuelUsed, time, closestApproach, landingSpeed}. Outcomes: landed, crashed_moon, crashed_planet, lost, timeout. sim.timeLeft() is your remaining budget in ms. sim.flights counts test flights.
      • 
        
    • Landed means touching the moon at a speed relative to it of at most safeLandingSpeed. Lowest fuel used among landings wins.
      •
